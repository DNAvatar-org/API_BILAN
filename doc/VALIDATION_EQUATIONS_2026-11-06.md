### CRITIQUE — `eq-intensite-raie-temperature-couche` (spectroscopie)

### MAJEUR — `eq-capacites-thermiques-chaleur-latente` (bilan-soleil-interieur)

La chaleur latente de fusion est comptée dans le manteau SOLIDE pendant toute l'histoire après l'océan de magma, aujourd'hui compris. La condition T_sol < T < T_liq utilise le solidus à 0 GPa (1 085,7 °C), sous toutes les T potentielles du manteau : à T₀ = 1 350 °C, le code traite le manteau comme fondu à 38 % et C vaut 1,48 × C_sensible. ### MAJEUR — `eq-adiabatique-humide-non-diluee` (atmosphere)

Le pas saturé viole l'équilibre hydrostatique : la part de dp prise par p_a suppose dp_c/dp_a = ρ_c/ρ_a (vapeur bien mélangée), alors que sur la courbe de saturation p_c décroît bien plus vite. La pression totale chute de 3,5 % de trop par mètre à 288 K / 1000 hPa, de 5 % à 300 K et de 25 % à 350 K (x_c = 0,42). Le gradient par mètre vaut alors 4,91 K/km au lieu de 4,75. L'erreur croît vers les atmosphères de vapeur que la carte revendique.

- **Preuve** : calculations.js:277 et 495 : dpa = −ρ g dz/(1 + p_c M_c/(p_a M_a)) ; puis p_c = pSatEau(T) (l.280, 498). Calcul node (scratchpad moist.js) : (Δp_total)/(−ρ g dz) = 1,0348 (288 K), 1,0500 (300 K), 1,2496 (350 K).
- **Correction** : dp_a = −ρ g dz / [1 + (p_c/p_a)(L/(R_c T))·γ], avec γ = penteHumide(T, p_a, p_c), de sorte que dp_a + dp_sat = −ρ g dz.

### MAJEUR — `eq-elargissement-par-pression` (spectroscopie)

### MAJEUR — `eq-auto-elargissement-vapeur` (spectroscopie)

### MAJEUR — `eq-bilan-energie-meridien` (chaine)

### MAJEUR — `eq-stratosphere-temperature-peau` (chaine)

La température de peau d'une couche grise vaut (OLR/2σ)^¼ : elle est chauffée par le rayonnement montant. Le code (et la carte, classée P) utilise S̄(1−A), qui n'est égal à l'OLR qu'à l'équilibre et sans flux intérieur. Quand F_int n'est pas négligeable (🔥, océan de magma où l'OLR dépasse de loin le solaire absorbé), la stratosphère est trop froide et l'OLR trop bas. Cela fausse aussi olrNetA, qui intègre le refroidissement de l'intérieur.

- **Preuve** : radiative/calculations.js:309 (T_peau = (🧲☀️🎱(1−🍰🪩📿)/(2σ))^¼, sans 🧲🌕). convergence/calculations_flux.js:503-505 : dans le cas fondu, 🧲🌕 = OLR − S_abs, l'OLR est donc dominé par F_int. geology/interieur.js:241-243 : olrNet(T) pilote le refroidissement du magma avec ce profil.
- **Correction** : Prendre T_peau = ((S̄(1−A) + F_int)/2σ)^¼, c'est-à-dire l'OLR d'équilibre visé, et le déclarer dans la carte. Pour l'océan de magma, utiliser l'OLR du pas précédent.

### `eq-equilibre-sommet-atmosphere` — réserve

Bilan d'énergie au sommet résolu en T_s : la conformité du code a été vérifiée terme à terme (calculations_flux.js:766).
